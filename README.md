# Martben Workspace Releases

Official release binaries for Martben Workspace - the administration panel for the Martben ecosystem.

## 📥 Download

Download the latest installer from the [Releases](https://github.com/JuanBenavides92/martben-workspace-releases/releases) page.

## 🔄 Auto-Updates

If you already have Martben Workspace installed, the app will automatically check for updates. Click **"Buscar Actualizaciones"** in the Dashboard to update immediately.
